# AgentAtelierR 1.0.4.1 MCP FishAudio

## 更新内容

- Android、Windows 同步 Fish Audio MCP，保留 `s2.1-pro`、`drama-3` 和“服务默认”；普通/ASMR 可分别设置音色，科洛蒂娅沿用内置音色。
- 修复持续 ASMR 原文与朗读语言不一致、翻译开关失效和重复译文；完善 Studio 配置与生成结果解析，避免失败后自动重复生成。
- Android 新增后台陪伴常驻通知：“莱莎一直陪在你的身边哦”，可从通知返回应用或停止后台运行。
- Android 通话时自动静音应用声音，通话结束且系统允许播放后恢复原有音量，涵盖语音、ASMR、音乐、环境音和闹钟。
- 新增通知权限、可选来电识别权限和厂商后台设置入口；Windows 同步共享音频代码并保持桌面播放兼容。

## 使用方法

1. Android 覆盖安装 APK；Windows 解压完整 ZIP 后运行 `AgentAtelierR.exe`。
2. 在“设置 → TTS → Fish Audio MCP（OAuth）”登录并读取工具列表，选择模型、填写普通/ASMR 音色 ID，点击“保存并使用 MCP”。ASMR 音色留空时沿用普通音色；指定模型走 Story Studio，“服务默认”走普通 TTS。
3. 持续 ASMR 跟随“设置 → 语言”。“独立翻译”开启时另行翻译，关闭时由主模型附译；不翻译或同语言时隐藏译文。
4. Android 允许通知后，在“设置 → 声音 → 后台陪伴与通话静音”展开查看状态，按需增强来电识别、配置厂商后台设置或恢复陪伴通知。
5. 第三方语音/视频通话识别及后台运行以手机系统支持为准；需要长期后台时，请允许自启动和后台运行。Studio 会在云端保存台词和生成音频，模型及积分以账号权益为准。
